# ستارلايت: ما دون النجوم

Creator: Ragnar (@abusqr)

## وصف اللعبة
لعبة متصفح عربية فصحى بالكامل بعنوان **ستارلايت: ما دون النجوم** (Starlight: Below the Stars).
رحلة ناضجة وشاعرية تبدأ من الحيرة، وتمر عبر عصابة ستارلايت، وتنتهي بمواجهة **الذات الأخيرة** وفهم أن العائق كان في الداخل.

## التشغيل
هذه نسخة **Static Web Game** تعمل بدون:
- npm
- Vite
- TypeScript
- Build

### تشغيل محلي
- افتح `index.html` مباشرة في المتصفح.
- أو استخدم خادم ملفات ثابتة بسيط، ثم افتح الصفحة.

### النشر عبر GitHub Pages
1. ارفع المشروع إلى المستودع.
2. افتح إعدادات GitHub Pages.
3. اختر النشر من الفرع الرئيسي ومن جذر المشروع.
4. ستعمل اللعبة مباشرة من `index.html` مع Phaser عبر CDN.

## تسلسل المشاهد
شاشة الدخول السينمائية → القائمة الرئيسية → اختيار النمط → اختيار الشخصية → اختيار الكلاس → مقدمة القصة → الساحة → بوابة الراحة → (التكرار حتى الجولة 30) → النهاية

مشاهد إضافية:
- ترتيب الخاتمين
- الإعدادات
- عن اللعبة
- شاشة الخسارة

## الشخصيات البشرية
- تم استبدال شكل اللاعب المربع بشخصيات بشرية بكسل آرت للمسافر والمسافرة مع أجزاء واضحة (رأس، جذع، ذراعان، ساقان) ومظاهر مميزة مثل الشارب والندبة للمسافر وندبات اليدين للمسافرة، مع حالات: وقوف، مشي، هجوم، تضرر، اندفاع.


## الكلاسات بصريًا وميكانيكيًا
- رونين: كاتانا وقوس، ضربة قطع واضحة، وإطلاق سهم، ويبدأ بـ 6 أسهم مع سقوط نادر للأسهم من الأعداء.
- طليعة الصحراء: سلاح ثقيل مع درع ظاهر، حركة أبطأ، صد ثم ضربة مضادة.
- صياد ستارلايت: خنجران وقوس قصير، حركة أسرع، فرصة ضربة حرجة أعلى مع ومضة حرجة.


## الأعداء والبوسات
- تم تحويل الأعداء من مربعات بسيطة إلى أشكال بكسل آرت بشرية/شبه بشرية مع حالات: مشي، تضرر، وموت بتلاشي.
- لكل بوس دخول سينمائي مع تعتيم واهتزاز وصوت، مع بطاقة عنوان عربية وشريط صحة واضح.
- الزعماء يملكون سلوكيات مميزة مثل مراوغة ظل الخوف وخداع قناع الإنكار وتكيّف الذات الأخيرة مع تكرار الهجوم.


## البيئة والخلفيات
- ساحة القتال أصبحت ببيئة بكسل آرت ليلية كاملة: أرضية واضحة، قمر، نجوم، بوابة مظلمة، ضباب خفيف، وجزيئات ضوء مع طبقات عمق.
- بوابة الراحة أصبحت منطقة هادئة بطابع شعري مع ضوء خافت وحجر/بوابة قديمة وتموضع مرئي لـ NPCs.
- مقدمة القصة صارت بخلفية سينمائية هادئة يظهر فيها اللاعب والعجوز بوضوح.
- شاشة النهاية بخلفية نجوم وباب يوحي بالتحرر والتصالح.


## إعادة تصميم HUD والقوائم
- تم إعادة تصميم HUD بصناديق بكسل مرتبة من اليمين إلى اليسار مع شريط صحة واضح للاعب.
- يظهر شريط صحة البوس عند المواجهات.
- أضيفت قائمة إيقاف داخل الساحة: متابعة، إعادة المحاولة، العودة إلى القائمة، الإعدادات.
- تم تحسين شاشات الإعدادات والخسارة والترتيب بتنسيق أوضح وشارات عربية مرتبة.


## تحسين الحوارات وNPCs
- تم تطوير صندوق الحوار ليعرض اسم المتحدث بوضوح، مع كتابة تدريجية للنص، وتعليمات: اضغط Enter للمتابعة.
- في نمط السرعة يمكن تخطي الحوار بسرعة أكبر.
- تم تعزيز حضور الشخصيات الجانبية بصريًا داخل بوابة الراحة مع ملامح أقرب لهوياتهم الدرامية.


## المؤثرات البصرية والأنيميشنات
- إضافة حالات حركة أوضح: وقوف، مشي، هجوم، تضرر، موت، اندفاع، وإطلاق سهم.
- إضافة مؤثرات Slash، أثر سهم، ومضات إصابة، وجزيئات عند ضرب البوس.
- إضافة غبار خفيف عند الاندفاع، وتلاشي عند موت الأعداء.
- تعزيز دخول البوس بتعتيم واهتزاز وصوت، مع نبض خفيف عند الذات الأخيرة.
- تفعيل انتقالات fade بين المشاهد الأساسية.


## تحسين الإحساس القتالي
- حركة اللاعب أصبحت أنعم عبر تسارع وتباطؤ تدريجي بدل الحركة الحادة.
- الاندفاع صار أوضح مع فائدة قتالية ومدة انتظار (Cooldown).
- الضربات لها مدى واضح، مع ارتداد خفيف للعدو عند الإصابة وارتداد خفيف للاعب عند تلقي الضرر.
- الأسهم محدودة وتظهر بوضوح، وسقوطها من الأعداء نادر.
- صعوبة الجولات ترتفع تدريجيًا بسرعة/كثافة محسوبة.
- البوسات تملك أنماطًا أبسط مع مؤشرات قبل الضربات الثقيلة، والذات الأخيرة تغيّر الأسلوب عند نصف الصحة.
