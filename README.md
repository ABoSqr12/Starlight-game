# ستارلايت: ما دون النجوم

Creator: Ragnar (@abusqr)

## وصف اللعبة
لعبة متصفح عربية فصحى بالكامل بعنوان **ستارلايت: ما دون النجوم** (Starlight: Below the Stars).
تحكي رحلة ناضجة عاطفية وشاعرية عن مواجهة الغضب والكبرياء والخوف والندم والإنكار، حتى مواجهة **الذات الأخيرة** في الجولة 30.

## التشغيل بدون npm
هذه النسخة **Static Web Game** ولا تحتاج:
- npm
- Vite
- TypeScript
- build

### تشغيل محلي سريع
1. افتح `index.html` مباشرة في المتصفح.
2. أو شغّل أي خادم ملفات ثابتة ثم افتح المشروع.

### نشر عبر GitHub Pages
1. ارفع الملفات إلى المستودع.
2. من إعدادات GitHub اختر Pages.
3. اجعل المصدر من الفرع الرئيسي وجذر المشروع.
4. ستعمل اللعبة مباشرة من `index.html` مع Phaser عبر CDN.

## التحكم
- الحركة: WASD أو الأسهم
- الهجوم الأساسي: Space أو زر الفأرة الأيسر
- الهجوم الثانوي: Q
- الاندفاع: Shift
- التفاعل: E
- الإيقاف: Esc
- تقديم الحوار: Enter
